# Подготовка к экзамену «1С:Специалист по платформе»

В данном репозитории я публикую свои решения практических задач по оперативному и бухгалтерскому учету в рамках подготовки к экзамену **«1С:Специалист по платформе 8.3»** (управляемое приложение).

## Структура репозитория

### 📁 `BU_01_FEFO_Average` — Бухгалтерский учет: списание FEFO и средняя себестоимость
Реализован учет продуктов питания в разрезе сроков годности на регистрах бухгалтерии:
* **План счетов и субконто:** настройка количественного и суммового учета по номенклатуре и срокам годности, документ «Операция» для ручного ввода проводок.
* **Алгоритм списания (FEFO):** списание товаров с наименьшим сроком годности по средней себестоимости сразу по всем срокам с выравниванием копеечных погрешностей.
* **Отчетность:** отчет «Себестоимость товаров» на СКД на базе виртуальной таблицы `ОстаткиИОбороты`.

### 📁 `BU_02_Batch_Costing` — Бухгалтерский учет: расчет себестоимости в разрезе сроков годности
Реализован партионный учет сроков годности с отложенным расчетом себестоимости:
* **Учет прихода и расхода:** контроль остатков в разрезе `(Номенклатура, Срок годности)`, автоподстановка и выбор доступных сроков годности в форме документа.
* **Регламентный расчет:** обработка «Формирование себестоимости» для расчета и заполнения средней себестоимости по срокам годности за выбранный период.

### 📁 `OU_Commission_Trade` — Оперативный учет комиссионной торговли (Задание 3)
Реализован цикл учета товаров на комиссии и взаиморасчетов с комитентами:
* **Списание себестоимости:** расчет по средней скользящей при проведении документа «Расходная накладная».
* **Новая методика проведения:** контроль отрицательных остатков вынесен после записи движений с использованием временных таблиц и парного отбора `(Товар, Договор) В (...)`.
* **Распределение выручки:** автоматический расчет вознаграждения комиссионера и суммы к выплате комитенту по проценту договора.

### 📁 `Task_02_Settlements` — Учет взаиморасчетов с контрагентами (Задание 2)
Реализованы механизмы учета расчетов по договорам и документам расчетов:
* **Регистры накопления:** настройка остаточных и оборотных регистров взаиморасчетов и разработка отчетов на СКД.

## Ключевые навыки, примененные в задачах
* **Бухгалтерский учет:** настройка планов счетов и видов субконто, виртуальные таблицы регистров бухгалтерии (`Остатки`, `ОстаткиИОбороты`), регламентный расчет себестоимости.
* **Оперативный учет:** оптимизация запросов, контроль остатков по новой методике проведения, расчет себестоимости, парные отборы в виртуальных таблицах.
* **Система компоновки данных (СКД):** разработка отчетов с использованием кросс-таблиц, условного оформления и пользовательских настроек.
* **Стандарты разработки 1С:** соблюдение правил клиент-серверного взаимодействия, использование временных таблиц и корректная работа с `СообщениеПользователю`.
